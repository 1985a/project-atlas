# Documentos históricos

Estos documentos son del **diseño inicial (v0.1, junio-julio de 2026)**. Se
conservan como referencia, pero **no describen el programa actual**: mencionan
comandos que no existen (`repair`, `workspace`...) y una arquitectura que se
sustituyó en la 0.2.

Para entender el código de hoy, empieza por:

- [`../ARQUITECTURA.md`](../ARQUITECTURA.md): qué hace cada módulo y cómo se conectan.
- [`../DESARROLLO.md`](../DESARROLLO.md): compilar, probar y las reglas del código.
- [`../rfc/`](../rfc/): decisiones de diseño que siguen vigentes.
